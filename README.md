# StudyWithMe AI · 清净自习室

一个极具高级感的沉浸式自习室网站，UI 严格贯彻 **Apple Liquid Glass（液态玻璃）** 设计语言。

## ✨ 特性

- **液态玻璃 UI**：半透明背景模糊 + 镜面高光 + 连续圆角 + 层叠景深，按钮/卡片/弹窗全部统一质感。
- **优质自然风景背景**：6 大场景（晨雾山林 / 雨落松林 / 湖光山色 / 海边晨曦 / 星空旷野 / 雪山静谧）+ 21 张精选高清图库，均来自 Unsplash 实拍，已逐一验证可加载。
- **背景风景切换**：场景浮层一键切换（带 1.6s 交叉淡入），并可开启「自动切换」轮播图库。
- **实时音乐调节**：纯 Web Audio 合成
  - 🎧 *音乐* — 生成式 Lo-fi 氛围（柔和和弦垫 + 五声音阶点缀 + 混响），无需任何音频文件；
  - 🔊 *背景音* — 随场景自动匹配的环境声（雨 / 海浪 / 风 / 林 / 夜虫 / 雪），音量滑块实时调节。
- **番茄钟**：25 / 45 / 50 / 90 分钟，专注 ↔ 休息自动循环，进度条、暂停 / 跳过 / 重置、完成提示音。
- **丝滑动画**：Ken Burns 背景缓动、视图淡入转场、元素错峰入场、弹性悬停、玻璃掠光、开场加载。
- **沉浸模式**：一键全屏并自动隐藏所有界面，鼠标移动时再优雅浮现。
- **中 / 英双语**、**移动端自适应**、状态本地持久化（场景 / 音量 / 时长 / 目标 / 语言）。

## 🚀 运行

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Safari 最新版）。

> 进入自习室时点击按钮会触发浏览器音频权限，从而开始播放生成式音乐与环境声。

如需本地服务器：

```bash
cd liquid-study
python3 -m http.server 5180
# 浏览器访问 http://localhost:5180
```

## 📁 结构

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构（首页 / 场景设置 / 自习室 三视图 + 浮层） |
| `styles.css` | 全部 Liquid Glass 样式与动画 |
| `audio.js`   | Web Audio 实时音频引擎（音乐 + 环境声） |
| `app.js`     | 交互逻辑：视图切换、场景、音量、番茄钟、沉浸模式、多语言 |

背景图片来自 [Unsplash](https://unsplash.com)，可免费用于个人与商业项目。
